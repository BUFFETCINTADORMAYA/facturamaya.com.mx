# 🌟 YAXTUN-OmniCore v2.0.0

## 🚀 Iniciar rápidamente

### **Opción 1: Descarga Automática (RECOMENDADO)**

**Windows:**
1. Descarga: `download-yaxtun.bat`
2. Doble click
3. Espera y listo

**Mac/Linux:**
```bash
curl -o download-yaxtun.sh https://raw.githubusercontent.com/BUFFETCINTADORMAYA/facturamaya.com.mx/repair-system-dev/download-yaxtun.sh
chmod +x download-yaxtun.sh
./download-yaxtun.sh
```

### **Opción 2: Descarga Manual

1. Descarga ZIP: https://github.com/BUFFETCINTADORMAYA/facturamaya.com.mx/archive/refs/heads/repair-system-dev.zip
2. Extrae
3. Abre carpeta `Yaxtun-OmniCore`
4. **Windows:** Doble click en `START.bat`
5. **Mac/Linux:** `bash START.sh`
