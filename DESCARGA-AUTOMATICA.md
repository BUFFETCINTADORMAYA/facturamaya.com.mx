# 🚀 YAXTUN-OmniCore - Descargador Automático

## 🎡 ¿Qué es esto?

Este descargador te permite descargar e instalar **Yaxtun-OmniCore** de forma automática desde GitHub, sin necesidad de clonar el repositorio manualmente.

---

## 🚀 INSTALACIÓN RÁPIDA

### **Windows:**

1. **Descarga:** `download-yaxtun.bat`
2. **Doble click** para ejecutar
3. Espera a que termine
4. Se abre la carpeta automáticamente
5. Doble click en `START.bat`
6. ¡Sistema listo en tu navegador!

### **Mac/Linux:**

```bash
# 1. Descargar el script
curl -o download-yaxtun.sh https://raw.githubusercontent.com/BUFFETCINTADORMAYA/facturamaya.com.mx/repair-system-dev/download-yaxtun.sh

# 2. Dar permisos de ejecución
chmod +x download-yaxtun.sh

# 3. Ejecutar
./download-yaxtun.sh

# 4. Seguir instrucciones en pantalla
```

---

## 📂 ¿Dónde se descarga?

- **Windows:** `C:\Users\[Tu Usuario]\Yaxtun-OmniCore`
- **Mac/Linux:** `~/Yaxtun-OmniCore`

---

## 🕐 Pasos después de descargar:

### **Windows:**
1. Se abre la carpeta automáticamente
2. Doble click en `START.bat`
3. Espera 30-60 segundos
4. Se abre portal en `http://localhost:3000`

### **Mac/Linux:**
1. Terminal se abre en la carpeta
2. Escribe: `bash START.sh`
3. Espera 30-60 segundos
4. Se abre portal en `http://localhost:3000`

## 🚗 Solucionar problemas

### **En Windows:**
- Si no funciona el descargador, descarga el ZIP manualmente desde:
  `https://github.com/BUFFETCINTADORMAYA/facturamaya.com.mx/archive/refs/heads/repair-system-dev.zip`
- Extrae y abre la carpeta `Yaxtun-OmniCore`
- Doble click en `START.bat`

### **En Mac/Linux:**
- Asegúrate que `curl` esté instalado: `curl --version`
- Si no: `brew install curl` (Mac) o `sudo apt-get install curl` (Linux)
