## 🚀 Instalación (SÚPER FÁCIL)

### Opción 1: Instalador Gráfico (Recomendado)
1. Descargar `Yaxtun-OmniCore-Installer.exe`
2. **Doble click** para ejecutar
3. Seleccionar opciones
4. ¡Listo! Sistema iniciado automáticamente

### Opción 2: Descomprimir ZIP
1. Descargar `Yaxtun-OmniCore.zip`
2. Descomprimir en `C:\Yaxtun-OmniCore`
3. Ejecutar `START.bat` o `START.sh`
4. Abrir navegador en `http://localhost:3000`

### Opción 3: Docker Manual (Avanzado)
```bash
cd Yaxtun-OmniCore
docker-compose up -d
```

## 📱 Cómo Usar

### Diagnóstico de Dispositivo
1. Conectar teléfono vía USB
2. Dashboard → "Detectar Dispositivo"
3. Seleccionar de la lista
4. Click en "Diagnosticar"
5. Ver análisis completo

### Crear Orden de Trabajo
1. Dashboard → "Nueva Orden"
2. Seleccionar dispositivo y fallas
3. Elegir tipo: "Diagnóstico" o "Reparación"
4. Asignar técnico y fecha
5. Seleccionar servicios y precios
6. **Generar PDF**

### Generar y Enviar PDF
1. Orden de Trabajo → "Generar PDF"
2. Seleccionar **plantilla** (Diagnóstico/Reparación)
3. Agregar **logo y firma** (opcional)
4. **Personalizar** diseño
5. **Enviar por Email** o **WhatsApp**
6. Cliente recibe en segundos

### Firma Digital del Cliente
1. Generar PDF con firma
2. Compartir enlace al cliente
3. Cliente firma en tablet/móvil
4. Guardar automáticamente
5. Certificado de trabajo completado

### Reparación iPhone
1. Conectar iPhone original
2. Extraer componentes críticos
3. Hacer backup automático
4. Cambiar componente físicamente
5. Conectar iPhone nuevo
6. Restaurar datos
7. **Face ID funciona perfectamente** ✅
