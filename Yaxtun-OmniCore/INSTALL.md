# Yaxtun-OmniCore Installation Instructions

## 🚀 Instrucción de Instalación Rápida

### Windows
1. Extraer `Yaxtun-OmniCore.zip`
2. **Doble click** en `START.bat`
3. Esperar a que se abra el navegador automáticamente
4. ¡Sistema listo en http://localhost:3000!

### Mac/Linux
1. Extraer `Yaxtun-OmniCore.zip`
2. Abrir Terminal en esa carpeta
3. Ejecutar: `bash START.sh`
4. Esperar a que se abra el navegador
5. ¡Sistema listo en http://localhost:3000!

---

## 🌐 Acceso al Sistema

- **Dashboard**: http://localhost:3000
- **API REST**: http://localhost:5000
- **Usuario**: admin@yaxtun.local
- **Contraseña**: admin123 (cambiar en primer acceso)
